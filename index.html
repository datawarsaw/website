      08 My AI Lab

      Experiments in public

      A working bench for cloud agents and local models.

      This site is also a lab notebook: cloud coding agents for fast iteration, and Ternary-Bonsai-27B for private local runs that never leave the machine. Nothing here pretends a backend is live when it is not.

      Cloud lane

      Remote coding agents

      Useful when you want broader context, parallel workers, and quick browser validation. Latency and provider policy travel with the request.

      • Best for: exploratory builds and comparative reviews
      • Constraint: data leaves the workstation

      Local lane

      Ternary-Bonsai-27B

      Positioned as the on-device model. It is slower and narrower than the strongest cloud options, but it keeps sensitive prompts local and is useful for offline drafting and constrained coding loops.

      • Best for: private notes, offline scaffolding, safe experimentation
      • Constraint: no implied live inference endpoint on this page

      Routing playground

      Choose a prompt type and destination. This is a client-side decision aid — it does not call a model API.
