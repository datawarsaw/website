# Project Roadmap

This roadmap tracks the development lifecycle of Data Warsaw, categorizing completed deliverables, active baseline states, and candidate future enhancements.

---

## 1. Completed Deliverables

- **Core Website Architecture:** Fully responsive, single-page data storytelling portfolio with custom vanilla JS/CSS architecture.
- **Hero Visualization:** Projective Canvas 2D hero graph with 3-layer analytical depth, elevated decision node, and damped pointer parallax.
- **Experience Orbit / Radar:** Interactive domain explorer connecting business challenges with analytical capabilities.
- **Methodology & Process Flow:** Structured narrative walkthrough of the analytical engagement cycle (Understand → Explore → Explain → Decide).
- **Live Warsaw Data Pulse:** Open-Meteo weather API integration with interactive scrub timeline and dynamic mobile tick adaptation.
- **Case Studies & Case Viewer:** Interactive statistical mini-plots and commercial impact summaries.
- **Project Documentation & Agent Memory:** Comprehensive project documentation suite (`docs/`, `evals/`, `AGENTS.md`).

---

## 2. Current State (Active Baseline)

- **Performance & Stability:** Zero build-step static deployment, lightweight asset footprint, 60fps interaction loops.
- **Accessibility & Motion:** Full support for `prefers-reduced-motion: reduce` with immediate static rendering fallbacks.
- **Mobile Fidelity:** Fully validated across 375px, 390px, 430px, and 1440px desktop breakpoints without horizontal overflow.

---

## 3. Candidate Future Improvements

- **Interactive Dataset Switcher for Weather Pulse:** Allow users to toggle historical seasonal weather comparisons (e.g. 7-day trend vs current 24h).
- **Enhanced Case Study Deep-Dives:** Optional modal or inline drill-downs for complex analytical workflows.
- **Automated CI Visual Regression Checks:** Lightweight automated headless screenshot tests across standard viewports.
