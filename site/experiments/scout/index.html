Scout — Autonomous Intelligence for X Bookmarks.

X API → Cloudflare Agent → GLM-4.7-Flash → Notion Knowledge Inbox

An autonomous edge agent running 24/7 on Cloudflare Workers that evaluates, context-enriches, and scores bookmarked technology signals, turning a chaotic social bookmark feed into structured, evidence-weighted research intelligence.

Trigger Frequency Every 5 Minutes (Cron)
Execution Runtime Cloudflare Workers + Agents SDK
Evaluation Engine @cf/zai-org/glm-4.7-flash
State Persistence Durable Objects / SQLite
01 Problem & Thesis

The Bookmarking Graveyard vs. Active Pipelines.

Why saving links is a broken paradigm for technical research, and how automated ingestion changes the equation.

High-signal technical breakthroughs, research papers, model releases, and architectural patterns emerge constantly on X. Yet bookmarks almost inevitably become an unstructured graveyard.

Bookmarking is frictionless and high-frequency, but reading, evaluating, and cataloging is low-frequency and cognitively expensive. Interesting threads sit unread, linked GitHub repositories are forgotten, and claims remain unverified.

The Core Idea

Bookmarking should not be a passive storage action. It should act as an intentional trigger for an autonomous research pipeline that evaluates evidence, extracts facts, and organizes structured knowledge without requiring manual triage.

Evidence Skepticism by Design

Social media is full of exaggerated claims, marketing benchmarks, and hype cycles. Scout operates on a strict principle of evidence conservatism: a social post alone should never automatically become ADOPT. The system deliberately isolates author claims from verifiable benchmarks and code evidence.

02 System Architecture

End-to-End Autonomous Flow.

Fully cloud-native execution running independently of the local workstation on Cloudflare's global edge network.

The entire pipeline executes at the edge using Cloudflare Workers and the Agents SDK. State is maintained inside a persistent Durable Object backed by embedded SQLite, preventing duplicate processing and tracking ingestion history.

03 Scout Intelligence

Evidence-Aware Decisioning.

How Scout evaluates technical content rather than simply saving raw links.

Instead of generating generic summaries, Scout executes a calibrated multi-factor analytical evaluation tailored to our active technology stack:

Relevance 0 – 10

Alignment with active domains: Data Analytics, Power BI, Python pipelines, Cloudflare Agents, and local AI orchestration.

Novelty 0 – 10

Differentiates genuine architectural innovations from rehashed tutorials or repackaged API wrappers.

Evidence Quality 0 – 10

Checks for reproducible code repositories, concrete benchmarks, and verifiable methodology over subjective claims.

Practical Fit & Complexity 0 – 10

Estimates friction, architectural overhead, and maintenance cost required to test or adopt.

Autonomous Decision Classification

Every evaluated signal is classified into one of three operational buckets:

IGNORE

Low Signal / Hype

Pure promotional material, unsubstantiated claims, or low-quality noise with no actionable substance.

WATCH

Promising Pattern

Interesting theoretical idea or early library that warrants observation as it matures or gains adoption.

TEST

Actionable Signal

High evidence quality, direct stack relevance, and clear immediate ROI. Generates a concrete test step.

04 Technology Stack

Production Implementation.

Lightweight, resilient edge architecture built on modern serverless foundations.

Layer Technology Role & Responsibility
Upstream Source X API v2 User-context OAuth 2.0 bookmark stream polling and tweet expansion.
Agent Runtime Cloudflare Workers Serverless edge execution with scheduled cron triggers and zero cold-start overhead.
State & Deduplication Durable Objects / SQLite Transactional persistence and fast index queries across processed bookmark IDs.
LLM Engine @cf/zai-org/glm-4.7-flash Edge inference via Cloudflare Workers AI for rapid structured extraction and rubric scoring.
Knowledge Base Notion API Knowledge Inbox database sync with categorized tags, scoring properties, and summaries.
05 Scope & Roadmap

Boundaries & Next Iteration.

Deliberate constraints kept for the MVP, and empirical observation priorities.

What Is Deliberately Not Built Yet (MVP Discipline)

  • ✕
    Multi-Hop Web Search Verification

    Kept out of the initial pipeline to preserve sub-second edge evaluation and avoid API cost sprawl.

  • ✕
    Deep Media / Video Frame Extraction

    Focus is currently restricted to text, linked articles, and repository code context.

  • ✕
    Multi-Platform Ingestion Feeds

    YouTube, Reddit, and GitHub release scrapers will only be added after X ingestion proves stable in practice.
