05 // Founder-led engineering

An independent, solo-founder engineering practice based in Warsaw. Software, analytics, business intelligence, and data remain the established foundation.

// Working principle

Understand the question.
Make the evidence legible.
Keep the decision human.

Warsaw Analytica is led by Michał Domaradzki. Agent Platform is the central engineering initiative: exploring how coding agents can work within a clear scope and return results that a person can inspect.

The practice combines implementation with analytical discipline: asking useful questions, examining evidence, explaining limitations, and making delivery decisions explicit.
